# Interface EclipsePluginWorkspace
    All Superinterfaces: [ApplicationInformationAccess](../../../../../ro/sync/exml/workspace/api/application/ApplicationInformationAccess.md), [ColorThemeUtilities](../../../../../ro/sync/exml/workspace/api/util/ColorThemeUtilities.md), [GlobalOptionsStorage](../../../../../ro/sync/exml/workspace/api/options/GlobalOptionsStorage.md), [MathFlowConfigurator](../../../../../ro/sync/exml/workspace/api/math/MathFlowConfigurator.md), [PluginWorkspace](../../../../../ro/sync/exml/workspace/api/PluginWorkspace.md), [ReferencesCustomizer](../../../../../ro/sync/exml/workspace/api/standalone/ReferencesCustomizer.md), [Workspace](../../../../../ro/sync/exml/workspace/api/Workspace.md), [WorkspaceUtilities](../../../../../ro/sync/exml/workspace/api/WorkspaceUtilities.md)   @API(type=NOT_EXTENDABLE, src=PUBLIC) public interface EclipsePluginWorkspaceextends [PluginWorkspace](../../../../../ro/sync/exml/workspace/api/PluginWorkspace.md), [MathFlowConfigurator](../../../../../ro/sync/exml/workspace/api/math/MathFlowConfigurator.md)
The Eclipse **Plugin Workspace** offers access utility methods or to access (and add listeners for) all opened editors from the Main editing area or from the DITA Maps editing area. Each opened editor contains one or more pages. The current editor page can be accessed trough the [WSEditor.getCurrentPage()](../../../../../ro/sync/exml/workspace/api/editor/WSEditor.md#getCurrentPage())method that returns specific editor implementations for Author and Text pages:
*  [WSAuthorEditorPage](../../../../../ro/sync/exml/workspace/api/editor/page/author/WSAuthorEditorPage.md) that provides access to Author editor page document controller or change tracking controller
*  [WSTextEditorPage](../../../../../ro/sync/exml/workspace/api/editor/page/text/WSTextEditorPage.md) that offers access to the edited document.
Both text based editor pages provides informations and actions regarding the caret position or the document current selection.
