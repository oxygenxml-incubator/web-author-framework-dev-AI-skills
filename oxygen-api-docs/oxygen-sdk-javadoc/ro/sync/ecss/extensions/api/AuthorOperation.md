@API(type=EXTENDABLE, src=PUBLIC) public interface AuthorOperationextends [Extension](Extension.md)
Interface defining an author extension operation. The operations are executed by the Author actions. All edits performed inside an AuthorOperation are part of a single compound edit ([AuthorDocumentController.beginCompoundEdit()](AuthorDocumentController.md#beginCompoundEdit()). If this behavior is not desirable, one can implement the [AuthorOperationWithCustomUndoBehavior](AuthorOperationWithCustomUndoBehavior.md) interface. More information on various subclasses can be found in the [user manual](https://www.oxygenxml.com/doc/ug-editor/topics/dg-default-author-operations.html).
