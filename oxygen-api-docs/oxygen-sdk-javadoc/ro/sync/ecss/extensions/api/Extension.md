@API(type=EXTENDABLE, src=PUBLIC) public interface Extension
The base interface for all Oxygen extensions classes. This interface is extended by two more specific interfaces [SWTExtension](SWTExtension.md) and [AWTExtension](AWTExtension.md) which divide the extensions into two subcategories SWT Eclipse extensions and AWT extensions. There are several kinds of extensions:
*  [ExtensionsBundle](ExtensionsBundle.md) representing a bundle for all extensions handlers,
*  [AuthorExtensionStateListener](AuthorExtensionStateListener.md) notified when the Document Type where the listener is defined was activated or deactivated in the detection process,
*  [AuthorOperation](AuthorOperation.md) defining an author extension operation,
*  [AuthorReferenceResolver](AuthorReferenceResolver.md) for the custom handlers used to expand content references,
*  [AuthorTableCellSpanProvider](AuthorTableCellSpanProvider.md) for classes which are responsible for providing information about the cell spanning,
*  [AuthorTableColumnWidthProvider](AuthorTableColumnWidthProvider.md) for classes which are responsible for providing information and handling modifications regarding table and column widths,
*  [TextDnDListener](../../../../../com/oxygenxml/editor/editors/TextDnDListener.md), [AuthorDnDListener](../../../../../com/oxygenxml/editor/editors/author/AuthorDnDListener.md) and [AuthorDnDListener](../../../exml/editor/xmleditor/pageauthor/AuthorDnDListener.md) extension listener for drag and drop operations,
*  [DocumentTypeCustomRuleMatcher](DocumentTypeCustomRuleMatcher.md) for providing custom matching to the document type it belongs to,
*  [ElementLocatorProvider](link/ElementLocatorProvider.md) capable of locating an element pointed by the supplied link,
*  [SchemaManagerFilter](../../../contentcompletion/xml/SchemaManagerFilter.md) filter for the schema manager,
*  [StylesFilter](StylesFilter.md) filter for the stylesheet's styles.
