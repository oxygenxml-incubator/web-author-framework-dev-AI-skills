### Table

public Table([Vector](https://docs.oracle.com/en/java/javase/17/docs/api/java.base/java/util/Vector.html) rowData, [Vector](https://docs.oracle.com/en/java/javase/17/docs/api/java.base/java/util/Vector.html) columnNames)

Constructs an oXygen-like table to display the values in the Vector of Vectors called rowData. The column names are given by columnNames. The Vectors contained in rowDatashould contain the values for one row. In other words, the value of the cell at row 1, column 5 can be obtained with the following code:
```
((Vector)rowData.elementAt(1)).elementAt(5);
```

  Parameters: rowData - The data for the new table. columnNames - The names of each column.
