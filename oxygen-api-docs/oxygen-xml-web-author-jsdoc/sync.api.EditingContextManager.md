# Class: EditingContextManager

##   [sync](sync.md)[.api](sync.api.md). EditingContextManager

#### new EditingContextManager()

 Editing context manager. To get access to this manager use [sync.api.Workspace#getEditingContextManager](sync.api.Workspace.md#getEditingContextManager). Initially, the context is built from the following URL parameters: - ditamap - dita.val.url
