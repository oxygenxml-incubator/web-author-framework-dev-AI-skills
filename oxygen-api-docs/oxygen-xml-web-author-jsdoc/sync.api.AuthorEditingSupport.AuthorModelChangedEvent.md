# Class: AuthorModelChangedEvent

##  AuthorModelChangedEvent

#### new AuthorModelChangedEvent(type, mutation)

 This event is triggered when the edited content changes.
This event is triggered on an [sync.api.AuthorEditingSupport](sync.api.AuthorEditingSupport.md). Here is an example of listening for this event:

```
editingSupport.listen(sync.api.AuthorEditingSupport.EventType.MODEL_CHANGED, function(e) {  // e is of type sync.api.AuthorEditingSupport.AuthorModelChangedEvent});
```
