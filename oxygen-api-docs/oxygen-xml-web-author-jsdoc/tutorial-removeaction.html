How to Remove a Toolbar Button

When oXygen XML Web Author is used for a group of users that are not supposed to perform some action, you can enforce this by removing it completely from the user interface.

For example, when used as a review tool, the change tracking support should be turned on by default, and the reviewers should not be able to turn it off. To achieve this, you can enable change tracking from the Administration Page and remove the "Toggle Change Tracking" action from the toolbar.

In order to remove an action from the toolbar and to prevent it from being performed using any other method (e.g. context menu, shortcut key) you can use the code snippet below:

    workspace.listen(sync.api.Workspace.EventType.EDITOR_LOADED, function(e) {
      var editor = e.editor;
      editor.listen(sync.api.Editor.EventTypes.ACTIONS_LOADED, function(e) {
        var actionId = 'Author/TrackChanges';
        editor.getActionsManager().unregisterAction(actionId);
      });
    });

Inspect the corresponding toolbar button using your browser Dev Tools and look for the "name" attribute of the corresponding div. The HTML will look something like:

<div class="goog-inline-block goog-toolbar-button" title="Toggle Change Tracking" role="button" name="Author/TrackChanges">

How to Remove an action only from the Toolbar

When you want to remove buttons from a specific toolbar while keeping them available in other places (like context menu), you can use the following approach:

function removeFromToolbar(editor) {
  editor.listen(sync.api.Editor.EventTypes.ACTIONS_LOADED, function(e) {
    var actionsConfig = e.actionsConfiguration;

    // Find the specific toolbar
    var targetToolbar = null;
    if (actionsConfig.toolbars) {
      for (var i = 0; i < actionsConfig.toolbars.length; i++) {
        var toolbar = actionsConfig.toolbars[i];
        if (toolbar.name === "Review") {  // Replace "Review" with your toolbar name
          targetToolbar = toolbar;
          break;
        }
      }
    }

    if (targetToolbar) {
      // Remove specific buttons from the toolbar
      for (var i = targetToolbar.children.length - 1; i >= 0; i--) {
        var action = targetToolbar.children[i];
        if (action.id === "Author/AcceptChange" || action.id === "Author/RejectChange") {
          targetToolbar.children.splice(i, 1);
        }
      }
    }
  });
}

// Usage
workspace.listen(sync.api.Workspace.EventType.EDITOR_LOADED, function(e) {
  removeFromToolbar(e.editor);
});

This code will:

  1. Keep the actions available in the context menu and review panel.
  2. Only remove them from the specified toolbar.
  3. Still allow the actions to be triggered via keyboard shortcuts or other means.

To find the correct toolbar name and action IDs:

  1. Inspect the toolbar using your browser's Dev Tools.
  2. Look for the toolbar's name attribute.
  3. For each button, look for the "name" attribute of the corresponding div element.
  4. The HTML will look something like this:
<div class="goog-toolbar" name="Review">
  <div class="goog-inline-block goog-toolbar-button" title="Accept Change" role="button" name="Author/AcceptChange">
  <div class="goog-inline-block goog-toolbar-button" title="Reject Change" role="button" name="Author/RejectChange">
</div>

The values of the name attributes are what you need to use in the code above.
