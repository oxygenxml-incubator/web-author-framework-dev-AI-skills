# Interface: GuidingArrowRenderer

##   [sync](sync.md)[.api](sync.api.md). GuidingArrowRenderer

Helper object used to render an arrow-line that can connect an HTML element to an XML node in the editor.Use [sync.api.AuthorWidgetsFactory#getGuidingArrowRenderer](sync.api.AuthorWidgetsFactory.md#getGuidingArrowRenderer) to get an instance.
    Since:
* 22.1

### Methods

#### hideArrow()

 Hide last rendered arrow. The arrow hides automatically but you can use this method if you want to hide it faster, when the source element is changed for example.

#### showArrowToNode(node [, sourceElement])

 Render an arrow that points to a node from the editor. The arrow is automatically hidden when the selection changes in the editor or when the editor is scrolled.**Note:** If the sourceElement parameter is missing or if it is located at the left of the editor then the arrow line will not be rendered, only its tip will be rendered at the given node.

##### Parameters:

  | Name | Type | Argument | Description |
  | -----------| -----------| -----------| -----------|
| `node` |   [Node](Node.md)   |    | The API DOM node to point to. |
| `sourceElement` |   HTMLElement   |  &lt;optional&gt;   | The optional source element from were the arrow line will start. |
