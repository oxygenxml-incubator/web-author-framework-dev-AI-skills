# Class: LinkOpenedEvent

##   [sync](sync.md)[.api](sync.api.md)[.Editor](sync.api.Editor.md). LinkOpenedEvent

#### new LinkOpenedEvent(url, external [, params] [, linkTarget])

 Link opened event.
Example of listening for this event:

```
editor.listen(sync.api.Editor.EventTypes.LINK_OPENED, function(e) {  // e is of type sync.api.Editor.LinkOpenedEvent});
```

##### Parameters:

  | Name | Type | Argument | Description |
  | -----------| -----------| -----------| -----------|
| `url` |   string   |    | The URL to be opened (that can contain an anchor) or an anchor (#fragment). For more details about anchors see the [OXY_URL Anchors](https://www.oxygenxml.com/doc/ug-waCustom/topics/oxy-url.html#section_anchors) section from the Customization Guide. |
| `external` |   boolean   |    | Whether the link should be opened in an external application. |
| `params` |   object   |  &lt;optional&gt;   | The parameters to pass to the new editor. |
| `linkTarget` |   [sync.api.Editor.LinkOpenedEvent.Target](sync.api.Editor.LinkOpenedEvent.md#.Target)   |  &lt;optional&gt;   | The target of the link. Specifies whether to open the link in a new window or in the current one. |
