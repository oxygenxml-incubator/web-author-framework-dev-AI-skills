# Class: PositionInformation

##   [sync](sync.md)[.api](sync.api.md). PositionInformation

#### new PositionInformation()

 Information describing a position.

### Methods

#### getNodeOfTag()

 In case of o position placed on a tag, this will return the element, the comment or the PI represented by the tag.

##### Returns:
     Type     [Node](Node.md)
#### getOffsetInText()

##### Returns:

 when `isOnText()` is `true` this will return the offset in the text node.
     Type     number | null
#### getParentNode()

 Get the element, the comment or the PI that contains the position. This method doesn't return text nodes.

##### Returns:
     Type     [Node](Node.md)
#### isOnEndTag()

##### Returns:

  `true` if position is on an end tag.
     Type     boolean
#### isOnStartTag()

##### Returns:

  `true` if position is on a start tag.
     Type     boolean
#### isOnText()

##### Returns:

  `true` if position is inside a text node.
     Type     boolean
