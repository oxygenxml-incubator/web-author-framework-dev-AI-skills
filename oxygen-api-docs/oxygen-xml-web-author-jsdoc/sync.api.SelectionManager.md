# Class: SelectionManager

##   [sync](sync.md)[.api](sync.api.md). SelectionManager

#### new SelectionManager()

 Author-specific selection manager. To get access to it use sync.api.AuthorEditingSupport#getSelectionManager. It can be used to retrieve and modify the selection as well as listening for selection changing events.

#### createEmptySelectionRelativeToNode(node, offset [, opt_fromNodeEndTag])

 Creates an empty selection at a position that is "offset" steps to the right of the start/end tag of the given "node". A step means either a content character, a start tag of a node or an end tag of a node. For example, with this XML content:`&lt;p&gt;I &lt;b&gt;like&lt;/b&gt; XML.&lt;/p&gt;`The following call:`selectionManager.createEmptySelectionRelativeToNode(p, 5, true)`Creates a position in the word "like" as presented below:`&lt;p&gt;I &lt;b&gt;li|ke&lt;/b&gt; XML.&lt;/p&gt;`

##### Parameters:

  | Name | Type | Argument | Description |
  | -----------| -----------| -----------| -----------|
| `node` |   [Node](Node.md)   |    | The element, comment or PI used as a reference for the selection position. |
| `offset` |   number   |    | The number of steps to the right of the start/end tag of the reference node. |
| `opt_fromNodeEndTag` |   boolean   |  &lt;optional&gt;   | true, to create the selection relative to the end tag of the given node rather than to its start. |
