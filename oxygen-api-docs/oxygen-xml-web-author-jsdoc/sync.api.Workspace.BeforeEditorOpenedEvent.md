# Class: BeforeEditorOpenedEvent

##   [sync](sync.md)[.api](sync.api.md)[.Workspace](sync.api.Workspace.md). BeforeEditorOpenedEvent

#### new BeforeEditorOpenedEvent(type, editor, options)

 Event generated before the editor is loaded. Its usage include:
*  adding new actions to the editor's action manager.
*  changing the startup options of the editor.
If the options can only be computed asynchronously, one can cancel the editor loading with preventDefault and call
```
editor.load(options);
```
later to load the editor with the new options.
Example of listening for this event:

```
workspace.listen(sync.api.Workspace.EventType.BEFORE_EDITOR_LOADED, function(e) {  // e is of type sync.api.Workspace.BeforeEditorOpenedEvent});
```

##### Parameters:

  | Name | Type | Description |
  | -----------| -----------| -----------|
| `type` |   string   | The type of the event. |
| `editor` |   [sync.api.Editor](sync.api.Editor.md)   | The editor that will be loaded. |
| `options` |   [sync.api.Workspace.LoadingOptions](sync.api.Workspace.md#.LoadingOptions)   | The options used to open the editor. |

### Members

#### options :[sync.api.Workspace.LoadingOptions](sync.api.Workspace.md#.LoadingOptions)

 The options used to load the editor. If these options are changed during the [sync.api.Workspace.EventType.BEFORE_EDITOR_LOADED](sync.api.Workspace.md#.EventType#.BEFORE_EDITOR_LOADED), they will be taken into account during the editor loading.
