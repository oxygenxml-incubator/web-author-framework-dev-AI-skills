#### ViewProperties

 The descriptor of a side-view.

##### Type:

*   Object

##### Properties:

  | Name | Type | Description |
  | -----------| -----------| -----------|
| `side` |   string   | Information about the side were to install the view. The possible values are: 'left'  /  'right'. Defaults to: 'right'. |
| `initiallyClosed` |   boolean  /  "string"   | Determines if the view should be closed. The possible values are: true  /  false  /  "forced". Defaults to false. If set to true, the view will be closed by default when the editor loads, unless the user has previously collapsed or expanded the side-view. If set to false, the view can be opened when the editor loads, provided it's the first view that’s enabled. If set to "forced", the view will always be closed when the editor loads. |
